# Safe KO

Offline, encrypted password vault for Android — by Khalid O.

- AES-256-GCM encryption, key derived from your master password (PBKDF2)
- Data stays on the device, never sent anywhere
- Auto-locks when the app leaves the screen; screenshots blocked
- Encrypted backup export/import

Download the latest APK: Releases → `latest` → `Safe-KO.apk`
